# 数值优化：第 1 至 19 章交互讲义

依据 Jorge Nocedal & Stephen J. Wright, *Numerical Optimization*, 2nd ed., Springer, 2006。中文讲解重新组织，保留数学条件、推导和原书例题的对应关系，加入原创工程案例与交互图。

当前完整讲义：**19 章、192 节、2781 个公式、44 个交互演示**。新增第 9–19 章共 99 节、11 个演示。

## 使用

直接用浏览器打开本目录的 `index.html` 即可。无需启动服务器，也不需要联网加载公式、字体或脚本。请使用支持原生 MathML 的现代浏览器（Chrome/Edge 109+，或 Firefox/Safari）。移动文件时须保留本目录内的文件结构。

也可以在仓库根目录启动静态服务器，然后访问 `/courses/numerical-optimization/`。例如：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

目录按节切换，不会一次加载全部正文到页面。左右方向键翻节；输入控件获得焦点时不会抢占按键。专注阅读收起目录。打印本节时自动展开推导与答案，打印后恢复折叠状态。
